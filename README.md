# Bootcamp-DIO-Formula-1
Aplicação backend inspirada no universo da Fórmula 1, desenvolvida com Node.js, TypeScript e Fastify. A API permite consultar informações de pilotos e equipes através de endpoints de listagem e busca, utilizando uma estrutura simples e performática para praticar conceitos de APIs REST, organização de código, CORS e manipulação de dados.
